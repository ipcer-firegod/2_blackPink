# HTML基础核心问答（清晰版，直接背诵）

## 1. HTML5 文档必须标签 + 各标签作用

### 必须包含的标签

`<!DOCTYPE html>`、`<html>`、`<head>`、`<body>` 是**HTML5文档必不可少**的标签。

### 各自作用

1. `<!DOCTYPE html>`：**文档类型声明**，告诉浏览器这是HTML5文档，必须写在第一行。
2. `<html>`：**根标签**，整个页面所有内容都包裹在里面，唯一的根节点。
3. `<head>`：**头部标签**，存放页面元信息（标题、编码、样式等），**内容不直接显示在页面上**。
4. `<body>`：**主体标签**，存放所有能在浏览器中看到的内容（文字、图片、按钮等）。

------

## 2. `<img>` 标签核心属性 + alt 属性作用

### 核心属性

1. `src`：**必须属性**，指定图片的路径（地址）。
2. `alt`：图片加载失败时的**替代文本**，也是搜索引擎识别图片的依据。
3. `width/height`：设置图片宽高（可选）。

### alt 属性作用

- 图片无法显示时，显示这段文字；
- 提升**可访问性**（屏幕阅读器会朗读alt内容）；
- 利于SEO（搜索引擎无法识别图片，靠alt识别内容）。

------

## 3. 相对路径三种情况 + 写法示例

### 相对路径三种情况

1. **同级**：文件和当前页面在同一个文件夹
2. **下级**：文件在当前文件夹的子文件夹里
3. **上级**：文件在当前文件夹的上一级文件夹里

### 路径写法

1. 图片在当前文件夹的 `img` 子文件夹：

```html
src="img/图片名.jpg"
```

1. 图片在当前文件夹的上一级文件夹：

```html
src="../图片名.jpg"
```

> `../` 代表**返回上一级目录**

------

## 4. 表单三部分 + <label> 两种关联方式

### 表单三部分

1. **表单标签**：`<form>`（定义表单范围、提交地址等）
2. **表单控件**：`<input>`、`<select>`、`<button>` 等输入元素
3. **提示信息**：文字说明、标签等

### `<label>` 关联控件两种方式

1. **嵌套式（包裹）**

```html
<label>用户名：<input type="text"></label>
```

1. **for-id关联式**

```html
<label for="user">用户名：</label>
<input type="text" id="user">
```

------

## 5. 块级元素 vs 内联元素 核心区别 + 举例

### 核心区别

1. **独占一行**：块级元素独占一行，内联元素不换行、多个并排显示
2. **宽高设置**：块级可以设置宽高，内联**设置宽高无效**
3. **默认宽度**：块级默认父元素100%宽度，内联默认内容宽度
4. **嵌套规则**：块级可嵌套块级/内联（p除外）；内联一般只能嵌套内联

### 常见元素

- **块级元素（3个）**：`<div>`、`<p>`、`<h1~h6>`
- **内联元素（3个）**：`<span>`、`<a>`、`<img>`

------

### 总结

1. HTML5必备4个标签：`DOCTYPE`、`html`、`head`、`body`
2. 图片`src`必写，`alt`是替代文本+SEO
3. 下级路径`img/`，上级路径`../`
4. 表单=表单标签+控件+提示；label两种关联：嵌套/for-id
5. 块级独占一行可设宽高，内联不换行宽高无效
