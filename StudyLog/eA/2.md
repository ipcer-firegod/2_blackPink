# CSS3核心知识面试速记（实习版）
## 一、核心知识点总结（带记忆要点+示例）
### 1. CSS基础认知
- **核心分工**：HTML管结构，CSS管样式/布局/动画
- **样式表分类**（面试高频问使用场景）：
  | 类型       | 书写位置               | 核心场景          | 示例                  |
  |------------|------------------------|-------------------|-----------------------|
  | 内联样式   | 标签style属性          | 临时改单个元素    | `<p style="color:red">` |
  | 内部样式   | head的style标签        | 单页面小型项目    | `<style>p{color:red}</style>` |
  | 外部样式   | 单独.css文件+link引入  | 中大型项目（推荐）| `<link href="index.css">` |

### 2. 选择器（面试必考，记优先级+常用场景）
#### 核心分类&记忆要点
| 选择器类型       | 语法示例                | 权重       | 高频场景                  |
|------------------|-------------------------|------------|---------------------------|
| 类选择器         | `.nav`                  | 0,0,1,0    | 多元素共享样式（按钮/卡片）|
| ID选择器         | `#header`               | 0,1,0,0    | 唯一元素（配合JS）|
| 后代选择器       | `.box p`                | 叠加       | 嵌套元素精准选择          |
| 伪类（:hover）   | `.btn:hover`            | 0,0,1,0    | 交互效果（悬停/表单焦点） |
| 伪元素（::after） | `.box::after`           | 0,0,0,1    | 插入内容/美化（清除浮动） |
| 属性选择器       | `[type="text"]`         | 0,0,1,0    | 表单/图标匹配             |

**选择器部分需要看 full 中有关内容！！！**

基础选择器（单个选择器，最常用）、
关系选择器（通过位置关系定位，精准选择）、
伪类选择器（选择“状态或位置特殊”的元素）、
伪元素选择器（选择“元素的特定部分”）、
属性选择器（按元素属性定位）

#### 关键考点
- 伪类LVHA顺序：`link`→`visited`→`hover`→`active`（hover必须在active前）
- `:nth-child(n)`：n可写数字/odd/even/公式（如`nth-child(2n)`选偶数）
- 伪元素`::before/after`：必须加`content`，默认内联元素

### 3. CSS三大特性（面试核心）
| 特性     | 核心规则                                  | 示例/考点                  |
|----------|-------------------------------------------|---------------------------|
| 继承性   | 文字相关样式可继承（color/font），盒模型不可 | `body{color:#333}` 子元素继承 |
| 层叠性   | 优先级相同时，后写的样式覆盖先写的        | `p{color:red}`→`p{color:blue}` 最终蓝色 |
| 优先级   | !important > 内联 > ID > 类/伪类/属性 > 标签/伪元素 > 通配符 | `#box .item` 权重(0,1,1,0) |

### 4. 盒子模型（布局必考）
- **组成**：content + padding + border + margin
- **核心问题**：
  1. `box-sizing: border-box`：width/height包含padding+border（推荐全局设置）
  2. 水平居中：块级元素`width+margin:0 auto`
  3. 外边距问题：
     - 兄弟折叠：取margin最大值，解决：只设单边margin
     - 父子塌陷：子margin-top带父下移，解决：父加`overflow:hidden`/border/padding

### 5. 文本样式（高频考点）
- 单行垂直居中：`line-height = 盒子高度`
- 文字溢出省略：
  ```css
  /* 单行 */
  .single {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
  }
  /* 多行（webkit内核） */
  .multi {
    display: -webkit-box;
    -webkit-line-clamp: 3;
    -webkit-box-orient: vertical;
    overflow: hidden;
  }
  ```
- font简写：`font: style weight size/line-height family`（必须有size+family）

### 6. 背景&过渡&阴影（美化高频）
- 背景复合写法：`background: 颜色 图片 重复 位置/尺寸`
- 线性渐变：`linear-gradient(to right, #ff6700, #4ecdc4)`
- 过渡`transition`：`transition: all 0.3s`（hover平滑变化）
- 盒子阴影：`box-shadow: X Y 模糊 扩散 颜色`（hover加阴影提升交互）

### 7. 样式初始化（面试常问）
- 简单重置（小型项目）：
  ```css
  * {margin:0; padding:0; box-sizing:border-box;}
  ul {list-style:none;}
  a {text-decoration:none; color:#333;}
  ```
- 中大型项目：用Normalize.css（保留有用默认样式，兼容性更好）

### 8. 图标优化（性能考点）
| 方式     | 核心原理                | 适用场景          |
|----------|-------------------------|-------------------|
| 精灵图   | background-position定位 | 复杂彩色小图标    |
| 字体图标 | 以字体形式引入          | 单色图标（灵活）|

## 二、面试常见题目（问答版）
### 1. CSS选择器有哪些？优先级如何计算？
**答**：
- 分类：基础选择器（类/ID/标签/通配符）、关系选择器（后代/子代/兄弟）、伪类/伪元素、属性选择器、分组选择器；
- 优先级：采用4位权重（a,b,c,d），`!important`权重无限大，内联样式(1,0,0,0)，ID选择器(0,1,0,0)，类/伪类/属性(0,0,1,0)，标签/伪元素(0,0,0,1)，通配符/继承(0,0,0,0)；
- 计算规则：权重叠加不进位（如`.box p`是0,0,1,1），权重高的生效，权重相同后写的生效。

### 2. 盒模型的两种模式是什么？如何解决外边距塌陷问题？
**答**：
- 两种模式：
  1. `content-box`（默认）：width/height仅包含内容区，实际尺寸=width+padding+border；
  2. `border-box`：width/height包含内容区+padding+border，推荐全局设置（方便布局）；
- 外边距塌陷（父子）：子元素的margin-top会导致父元素一起下移，解决方案有3种：
  1. 给父元素添加顶部边框（如`border-top: 1px solid transparent`）；
  2. 给父元素添加顶部内边距（如`padding-top: 1px`）；
  3. 给父元素设置`overflow: hidden`（最常用，不影响布局）。

### 3. 如何实现单行/多行文字溢出显示省略号？
**答**：
- 单行文字溢出：需同时设置3个属性：
  ```css
  .single-ellipsis {
    overflow: hidden;    /* 溢出隐藏 */
    text-overflow: ellipsis; /* 溢出显示省略号 */
    white-space: nowrap; /* 文字不换行 */
  }
  ```
- 多行文字溢出（仅支持WebKit内核浏览器，如Chrome）：
  ```css
  .multi-ellipsis {
    display: -webkit-box;
    -webkit-box-orient: vertical; /* 文本垂直排列 */
    -webkit-line-clamp: 3; /* 限制显示3行 */
    overflow: hidden;
  }
  ```

### 4. CSS的三大特性是什么？继承性有什么特点？
**答**：
- 三大特性：继承性、层叠性、优先级；
- 继承性：子元素会自动继承父元素的样式，**仅文字相关样式可继承**（如color、font-family、font-size、line-height、text-align），盒模型相关样式（width、height、margin、padding、border、background）不可继承；
- 层叠性：多个CSS规则作用于同一元素，优先级相同时，后定义的样式覆盖先定义的；
- 优先级：不同选择器有不同权重，权重高的样式优先生效。

### 5. 如何实现元素水平居中？分情况说明
**答**：
- 块级元素水平居中：给元素设置固定宽度（width），再设置`margin: 0 auto`；
- 行内/行内块元素：给父元素设置`text-align: center`；
- （拓展，实习可能问）Flex布局：父元素`display: flex; justify-content: center`（后续布局常考）。

### 6. :before和:after伪元素的使用注意事项？
**答**：
1. 伪元素使用`::`（CSS3规范），低版本浏览器兼容`:`；
2. 必须设置`content`属性（无内容时写`content: ""`）；
3. 默认是内联元素，如需设置宽高，需改为`display: inline-block`或`block`；
4. 插入的内容在元素内部，属于虚拟元素，无法通过JS获取。

### 7. 为什么要做样式初始化？常用的初始化方式有哪些？
**答**：
- 原因：不同浏览器对HTML元素有默认样式（如body默认margin:8px、ul默认padding-left:40px），导致跨浏览器显示不一致，样式初始化可消除这种差异；
- 两种方式：
  1. 简单重置（小型项目）：通过通配符和标签选择器清除默认样式（如`* {margin:0; padding:0; box-sizing:border-box}`）；
  2. Normalize.css（中大型项目）：保留有用的默认样式，仅统一不一致的样式，兼容性更好，需通过link引入。

### 8. transition过渡效果的使用要点？
**答**：
1. 语法：`transition: 过渡属性 过渡时长`，如`transition: background 0.3s`；
2. 过渡属性：可指定具体属性（如box-shadow、color），或用`all`表示所有属性；
3. 触发条件：需通过用户交互（hover、focus）或JS触发属性变化，直接写的样式不会过渡；
4. 时长单位：s（秒）或ms（毫秒），如0.3s（推荐）、300ms。
