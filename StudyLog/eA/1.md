# HTML核心知识面试总结（前端实习版）
## 一、核心知识速记（带示例+记忆要点）
### 1. HTML基础与语义化
- **核心定义**：HTML是超文本标记语言，非编程语言，核心是「语义化」（按内容含义选标签）。
- **语义化重要性**：
  - 代码易维护、SEO友好、提升可访问性（屏幕阅读器适配）。
- **记忆要点**：优先用`<h1>`/`<article>`/`<nav>`等语义标签，而非纯`<div>`+样式。
- **示例**：用`<h1>`做页面主标题（唯一），`<nav>`包裹导航栏，`<article>`包裹文章主体。

### 2. HTML文档基本结构（必背）
```html
<!DOCTYPE html> <!-- HTML5声明，必须在最顶部 -->
<html lang="zh-CN"> <!-- 根元素，声明语言 -->
  <head> <!-- 机器可读元数据 -->
    <meta charset="UTF-8"> <!-- 避免乱码，必加 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- 移动端适配 -->
    <title>页面标题</title>
  </head>
  <body> <!-- 页面显示内容 -->
    核心内容
  </body>
</html>
```
- **记忆要点**：`meta charset`和`viewport`是移动端开发必加；`DOCTYPE`无闭合标签。

### 3. 标签语法与关系
| 类型     | 规则                                                       |
| -------- | ---------------------------------------------------------- |
| 双标签   | 开始+内容+结束（如`<p>段落</p>`），绝大多数标签属于此类    |
| 单标签   | 无内容（如`<img>`/`<br>`/`<hr>`）                          |
| 属性规则 | 键值对（`src="xxx"`），值必须加引号，属性无先后顺序        |
| 嵌套关系 | 父子标签（如`<head>`包含`<title>`），`<p>`不能嵌套块级元素 |
| 并列关系 | 同级标签（如`<head>`和`<body>`）                           |

### 4. 高频核心标签（面试重点）
#### （1）文本类（语义优先）
- 标题：`<h1>`~`<h6>`，`h1`每页仅1个，层级不超3级；
- 段落：`<p>`（独占一行，不可嵌套块级）；
- 强调：`<strong>`（重要性加粗）、`<em>`（语气倾斜），替代无语义的`<b>`/`<i>`；
- 示例：`<p>原价<del>2499</del>，现价<strong>2099</strong></p>`。

#### （2）媒体类
- 图片`<img>`（单标签，必加`src`+`alt`）：
  ```html
  <img src="img/avatar.png" alt="用户头像" title="点击查看"> <!-- alt提升可访问性 -->
  ```
  - 路径：相对路径（`./`同目录/`../`上级/`img/`下级），绝对路径仅用于外部资源；
  - 格式：JPG（照片）、PNG（透明图标）、GIF（简单动画）、WebP（高压缩）。

#### （3）链接类`<a>`
- 核心属性：`href`（跳转目标）、`target="_blank"`（新窗口打开外部链接）；
- 锚点导航（高频）：
  ```html
  <a href="#chapter1">跳转到第一章</a>
  <h2 id="chapter1">第一章</h2>
  <style>html {scroll-behavior: smooth;}</style> <!-- 平滑滚动 -->
  ```
- 特殊链接：`href="mailto:xxx"`（邮件）、`href="xxx.zip"`（下载）、`href="#"`（空链接）。

#### （4）列表类（结构化内容）
| 列表类型 | 标签组合         | 适用场景                 | 示例（导航栏）                                      |
| -------- | ---------------- | ------------------------ | --------------------------------------------------- |
| 无序列表 | `<ul>+<li>`      | 导航、商品列表（最常用） | `<nav><ul><li><a href="/">首页</a></li></ul></nav>` |
| 有序列表 | `<ol>+<li>`      | 步骤、排名               | `<ol><li>创建HTML文件</li></ol>`                    |
| 描述列表 | `<dl>+<dt>+<dd>` | 术语解释、页脚分类       | `<dl><dt>家电</dt><dd>电视</dd></dl>`               |

#### （5）表单类（用户交互核心）
- 容器：`<form>`（`action`指定后端地址）；
- 核心控件（`<input>`为主，`type`切换类型）：
  | type值   | 作用     | 关键属性                            |
  | -------- | -------- | ----------------------------------- |
  | text     | 单行文本 | placeholder（提示）、maxlength      |
  | password | 密码框   | 同text                              |
  | radio    | 单选框   | name（分组互斥）、checked（默认选） |
  | checkbox | 复选框   | 同radio                             |
  | file     | 文件上传 | accept="image/*"（限制图片）        |
- 其他控件：
  - 多行文本：`<textarea rows="5" placeholder="反馈意见"></textarea>`；
  - 下拉框：`<select><option value="bj" selected>北京</option></select>`；
  - 按钮：`<button type="submit">提交</button>`（type必加，区分submit/reset/button）；
  - 辅助标签`<label>`（高频）：
    ```html
    <!-- 方式1：for+id关联（推荐） -->
    <input type="radio" id="male" name="sex">
    <label for="male">男</label>
    <!-- 方式2：直接包裹 -->
    <label><input type="radio" name="sex">女</label>
    ```

### 5. 块级/内联元素（布局基础）
| 类型     | 核心特点                  | 代表标签                                        |
| -------- | ------------------------- | ----------------------------------------------- |
| 块级元素 | 独占一行、可设宽高        | `<h1>`~`<h6>`、`<p>`、`<div>`、`<ul>`、`<form>` |
| 内联元素 | 不独占一行、不可设宽高    | `<a>`、`<strong>`、`<span>`                     |
| 特殊     | `<img>`可设宽高（行内块） | ——                                              |
- 记忆：可通过CSS`display`修改（`block`/`inline`/`inline-block`）。

```html
<h1>~<h6>、<p>、<div>、<ul>、<table>、<form>、dl、dt、dd

<strong>、<em>、<a>、<span>、b、、input、select、
```

### 6. 字符实体（避坑）
- 常用：`&nbsp;`（不换行空格）、`&lt;`（<）、`&gt;`（>）、`&copy;`（©）；
- 示例：`<p>HTML标签语法：&lt;div&gt;</p>`。

## 二、面试常见题目（问答版）
### 1. 什么是HTML语义化？为什么要做语义化？
**答**：  
语义化是指根据内容的结构和含义选择恰当的HTML标签（而非仅靠`<div>`/`<span>`）。  
核心原因：  
1. 开发层面：代码结构清晰，易维护（他人接手能快速理解标签用途）；
2. SEO层面：搜索引擎通过语义标签识别核心内容，提升页面排名；
3. 可访问性：屏幕阅读器能通过语义标签准确解读内容，适配视障用户。

### 2. `<img>`标签的`alt`属性有什么作用？
**答**：  
`alt`是图片的备用文本，核心作用：  
1. 图片加载失败时显示，告知用户图片内容；
2. 屏幕阅读器读取`alt`内容，帮助视障用户理解图片；
3. 辅助SEO（搜索引擎无法识别图片内容，可通过`alt`判断）。  
  补充：`title`是鼠标悬停时的提示文本，属于体验优化，非必加。

### 3. HTML文档中`<meta name="viewport">`的作用是什么？
**答**：  
该标签是移动端适配的核心，用于设置页面视口（可视区域）的行为：  
- `width=device-width`：页面宽度等于设备宽度；
- `initial-scale=1.0`：初始缩放比例为1:1；
- 若省略该标签，移动端页面会以PC端宽度（980px）渲染，导致页面缩放异常、内容显示不全。

### 4. 简述`<a>`标签的锚点导航实现方式？
**答**：  
锚点导航用于同一页面内的快速跳转，步骤：  
1. 给目标元素添加唯一`id`属性（如`<h2 id="chapter1">第一章</h2>`）；
2. 创建跳转链接，`href`值为`# + 目标id`（如`<a href="#chapter1">跳转到第一章</a>`）；
3. 可选优化：添加`html {scroll-behavior: smooth;}`实现平滑滚动。

### 5. 块级元素和内联元素的区别？举例说明？
**答**：  
核心区别有2点：  
1. 显示方式：块级元素独占一行（如`<div>`/`<p>`），内联元素不独占一行（如`<a>`/`<span>`）；
2. 样式控制：块级元素可直接设置宽高，内联元素宽高由内容决定，无法直接设置；
  补充：`<img>`是特殊的行内块元素（可设宽高、不独占一行）；元素显示模式可通过CSS`display`修改。

### 6. 表单中`<label>`标签的作用？如何使用？
**答**：  
`<label>`用于关联表单控件和文本说明，提升可访问性（点击文本可聚焦对应控件，尤其适配单选/复选框）。  
使用方式有2种：  
1. `for + id`关联（推荐）：给控件加`id`，`<label>`的`for`值等于控件`id`（如`<input id="male"><label for="male">男</label>`）；
2. 直接包裹：`<label>`直接包裹控件和文本（如`<label><input type="checkbox">同意协议</label>`）。

### 7. `<h1>`标签的使用规范？为什么不能多个`<h1>`？
**答**：  
规范：  
1. 每个页面仅能使用1个`<h1>`，用于页面核心标题（如网站logo、文章主标题）；
2. 标题层级建议不超过3级（`h1`→`h2`→`h3`），保证语义清晰。  
  原因：多个`<h1>`会导致语义混乱，搜索引擎无法识别页面核心主题，降低SEO效果；同时屏幕阅读器解读时会误导视障用户。

### 8. HTML中的相对路径有哪几种写法？举例说明？
**答**：  
相对路径基于当前HTML文件的位置，分3种：  
1. 同一目录：直接写文件名（如`<img src="pig.jpg">`或`<img src="./pig.jpg">`，`./`可省略）；
2. 下级目录：子文件夹名+文件名（如图片在`img`文件夹：`<img src="img/pig.jpg">`）；
3. 上级目录：`../`+文件名（如HTML在`code`文件夹，图片在上级：`<img src="../pig.jpg">`）。

### 9. 表单中`radio`单选框如何实现互斥？
**答**：  
给同组的`radio`控件设置相同的`name`属性即可实现互斥（如性别选择：`<input type="radio" name="sex" id="male">`和`<input type="radio" name="sex" id="female">`）。  
补充：可通过`checked`属性设置默认选中项。

### 10. 为什么不推荐用表格做页面布局？
**答**：  
1. 语义问题：表格的核心语义是展示结构化数据（如成绩表），用于布局违背语义化原则；
2. 维护问题：表格嵌套层级多，修改和维护成本高；
3. 响应式问题：表格难以适配移动端，调整样式复杂；
4. 替代方案：使用`<div>`/`<section>`等语义标签+CSS（Flex/Grid）实现布局。
