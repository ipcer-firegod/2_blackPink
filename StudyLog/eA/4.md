# CSS交互动效面试核心总结（附高频面试题）
## 一、核心知识点速记（面试高频）
### 1. transform（变换）—— 动效基础（无布局影响+GPU加速）
#### （1）2D变换（必会）
| 类型 | 核心用法 | 面试高频场景 | 易错点 |
|------|----------|--------------|--------|
| 平移 | `translateX/Y(x/y)`、`translate(x,y)` | 元素居中（`top:50%;left:50%;transform: translate(-50%,-50%)`）、悬停偏移 | 百分比相对**元素自身**，非父容器 |
| 旋转 | `rotate(deg)` + `transform-origin`（控制旋转基点） | 图标旋转、卡片翻转 | 行内元素需转`inline-block/block`才生效 |
| 缩放 | `scaleX/Y(n)`、`scale(n)` | 悬停放大、按钮点击反馈 | 仅视觉缩放，不改变元素占位 |
| 倾斜 | `skewX/Y(deg)` | 斜切导航栏 | 形状改变需注意兼容性 |
- 复合写法：执行顺序**从右到左**（例：`transform: translate(100px) rotate(45deg)` → 先旋转再平移）

#### （2）3D变换（立体效果，面试常考卡片翻转）
| 核心属性 | 作用 | 使用位置 |
|----------|------|----------|
| `perspective: 1000px` | 模拟透视（数值越小透视越强） | 父元素（子元素统一生效） |
| `transform-style: preserve-3d` | 保留3D空间，避免子元素被压平 | 父元素（3D卡片必需） |
| `backface-visibility: hidden` | 隐藏元素背面 | 子元素（卡片翻转隐藏背面） |
| `rotateX/Y/Z(deg)` | 3D旋转（rotateZ=2D rotate） | 子元素 |
- 经典案例（3D卡片翻转）：
```css
.card-container { perspective: 1000px; transform-style: preserve-3d; }
.card { transition: transform 0.5s; position: relative; }
.card-front, .card-back { 
  position: absolute; width: 100%; height: 100%; 
  backface-visibility: hidden; /* 隐藏背面 */
}
.card-back { transform: rotateY(180deg); }
.card-container:hover .card { transform: rotateY(180deg); }
```

### 2. transition（过渡）—— 平滑动效
- 完整语法：`transition: 过渡属性 时长 速度曲线 延迟`（例：`transition: all 0.5s ease 0.2s`）
- 高频速度曲线：
  - `ease`（默认）：慢→快→慢（按钮悬停）
  - `linear`：匀速（进度条）
  - `cubic-bezier()`：自定义（创意动效）
- 核心：仅支持“两帧状态切换”，无法实现复杂多帧动画

### 3. animation（动画）—— 复杂动效核心
#### （1）核心流程
1. 定义关键帧：`@keyframes 名称 { 0% {…} 50% {…} 100% {…} }`
2. 使用动画：`animation: 名称 时长 速度曲线 延迟 播放次数 方向 填充模式`（名称+时长必写）

#### （2）高频属性
| 属性 | 高频值 | 场景 |
|------|--------|------|
| `animation-iteration-count` | `infinite` | 加载动画无限循环 |
| `animation-timing-function` | `steps(n)` | 逐帧动画（精灵图） |
| `animation-fill-mode` | `forwards` | 动画结束保留最后一帧 |
| `animation-direction` | `alternate` | 正反向交替播放 |

#### （3）逐帧动画（面试常考精灵图）
```css
@keyframes load {
  0% { background-position: 0 0; }
  100% { background-position: -13700px 0; } /* 精灵图总宽度 */
}
.loader {
  width: 548px; height: 513px; /* 单帧尺寸 */
  background: url(loader-sprite.png) no-repeat;
  animation: load 1s steps(25) infinite; /* steps(帧数) */
}
```

### 4. 实用动效技巧（面试加分项）
| 效果 | 核心代码 | 场景 |
|------|----------|------|
| 流光渐变边框 | 父容器`overflow:hidden` + 渐变子元素`animation: rotate 2s linear infinite` + 内容层遮挡 | 按钮、卡片装饰 |
| 元素倒影 | `-webkit-box-reflect: below 1px linear-gradient(transparent, rgba(0,0,0,0.2))` | 图片/按钮视觉增强 |
| 毛玻璃 | `backdrop-filter: blur(10px)` + 半透背景 | 弹窗、导航栏 |
| 父选择器联动 | `.nav:has(.item:hover) { grid-template-columns: 2fr 1fr 1fr; }` | 子元素hover改变父布局 |

### 5. 性能优化（面试必问）
- 优先用`transform`/`opacity`做动画（GPU加速），避免修改`width`/`top`/`margin`（触发重排）

## 二、面试常见题目（问答形式）
### 1. 基础概念类
#### Q1：transform和普通定位（top/left）做动画的区别？
A：① `transform`仅视觉变换，不破坏文档流，不触发重排/重绘（GPU加速）；② `top/left`修改会触发布局重排，性能差；③ `transform`的百分比相对元素自身，`top/left`相对父容器。

#### Q2：transition和animation的区别？
A：① `transition`是“状态过渡”，仅支持两帧切换，需触发条件（hover/点击）；② `animation`通过关键帧定义多帧状态，可自动播放、循环，支持更复杂动效；③ 两者都依赖GPU加速（优先transform/opacity）。

#### Q3：3D卡片翻转的实现要点？
A：① 父容器加`perspective`（透视）+ `transform-style: preserve-3d`（保留3D空间）；② 卡片正反两面绝对定位，加`backface-visibility: hidden`（隐藏背面）；③ 背面初始`rotateY(180deg)`，hover时卡片整体`rotateY(180deg)`；④ 配合transition实现平滑过渡。

### 2. 实操场景类
#### Q4：如何实现一个无限循环的加载动画（精灵图版）？
A：① 准备包含N帧的精灵图；② 定义`@keyframes`，通过`background-position`移动精灵图（从0到精灵图总宽度负值）；③ 给元素设置单帧尺寸+精灵图背景；④ 动画属性设置：`animation: 名称 1s steps(N) infinite`（steps的N等于帧数）。

#### Q5：实现按钮悬停时的流光边框效果，思路是什么？
A：① 按钮父容器设`position: relative` + `overflow: hidden` + 圆角；② 内部加渐变子元素（`linear-gradient`多色渐变），绝对定位且宽度设为200%；③ 给渐变子元素加平移/旋转动画；④ 再叠加一个内容子元素（白色背景），通过`inset: 3px`缩进项圈，只露出渐变边框；⑤ 最终hover时可加快动画速度（可选）。

### 3. 性能优化类
#### Q6：CSS动画卡顿的原因有哪些？如何优化？
A：**原因**：① 动画属性触发重排（如width/top）；② 无GPU加速；③ 透视/阴影等复杂效果过度使用。
**优化**：① 优先用`transform`/`opacity`做动画；② 给动画元素加`will-change: transform`（提前告知浏览器优化）；③ 减少`box-shadow`/`filter`等昂贵属性；④ 3D变换时合理设置`perspective`，避免过度透视。

#### Q7：为什么transform的复合写法执行顺序是从右到左？
A：CSS transform的复合函数遵循“矩阵乘法”规则，右侧函数先作用于元素的初始状态，左侧函数作用于右侧变换后的状态。例如`transform: translate(100px) rotate(45deg)`，先旋转（基于元素原点），再平移（基于旋转后的坐标系），符合视觉逻辑。

### 4. 拓展加分类
#### Q8：CSS的:has()选择器有什么用？举个交互例子？
A：`:has()`是父选择器，可根据子元素状态选择父元素，解决了CSS无法反向选择的问题。例：导航栏中，当某个导航项（.item）hover时，让父容器（.nav）调整列宽：
```css
.nav:has(.item:hover) {
  grid-template-columns: 2fr 1fr 1fr; /* hover项占2份，其他占1份 */
}
```

#### Q9：backface-visibility:hidden的作用？什么时候用？
A：作用是隐藏元素的“背面”（3D变换时元素翻转后的面），默认背面是镜像显示。常用于3D卡片翻转、3D轮播等场景，避免翻转时看到背面的内容（如卡片背面的文字/图片透显）。

## 三、记忆口诀（快速回顾）
1. transform：2D平移旋转缩放斜，3D透视保3D，背面隐藏不穿帮；
2. transition：属性时长曲线延，两帧过渡靠触发；
3. animation：关键帧定多状态，名称时长不能少，steps逐帧精灵图；
4. 性能：transform/opacity优先，重排属性要避开。
