# CSS前沿技术面试核心总结（附高频面试题）
## 一、核心技术模块速记（易理解+易记忆）
### 1. SVG 动画（矢量动画）
- **核心优势**：矢量无损缩放、可代码编辑、支持CSS/JS交互，适合图标/绘制动画。
- **核心属性**：
  - `fill`：填充色，`stroke`/`stroke-width`：描边颜色/宽度；
  - `stroke-dasharray`（虚线模式）+ `stroke-dashoffset`（虚线偏移）：实现“画笔绘制”动画。
- **关键实现（画笔效果）**：
  1. JS获取路径长度：`path.getTotalLength()`；
  2. 初始隐藏：`stroke-dasharray/stroke-dashoffset = 路径长度`；
  3. 动画：`@keyframes` 将`stroke-dashoffset`减至0。
- **面试记忆示例**：三角形SVG绘制动画（核心代码精简版）
```html
<svg><path id="path" d="M100 20 L20 180 L180 180 Z" fill="none" stroke="#ff6700"/></svg>
<script>const len = document.getElementById('path').getTotalLength(); path.style.strokeDasharray = path.style.strokeDashoffset = len;</script>
<style>#path { animation: draw 2s linear forwards; } @keyframes draw { 100% { stroke-dashoffset: 0; } }</style>
```

### 2. clip-path 裁剪（自定义形状）
- **核心作用**：裁剪元素显示区域，仅展示区域内内容，支持内置形状/自定义路径。
- **常用语法**：
  - 内置：`circle(40% at 50% 50%)`（圆形头像）、`polygon(50% 0%, 0% 100%, 100% 100%)`（三角形）；
  - 兼容：Safari需加`-webkit-`前缀。
- **面试记忆示例**：三角形图片裁剪
```css
.triangle-img {
  width: 200px; height: 200px;
  -webkit-clip-path: polygon(50% 0%, 0% 100%, 100% 100%);
  clip-path: polygon(50% 0%, 0% 100%, 100% 100%);
}
```

### 3. backdrop-filter 背景滤镜（毛玻璃）
- **核心区别**：`filter`作用于元素自身，`backdrop-filter`作用于元素背后背景（需配合半透明背景）。
- **核心用法**：`backdrop-filter: blur(10px)`（毛玻璃核心），Safari加`-webkit-`。
- **面试记忆示例**：毛玻璃导航栏
```css
.nav {
  position: fixed; width: 100%;
  background: rgba(255,255,255,0.6); /* 半透明必加 */
  -webkit-backdrop-filter: blur(10px);
  backdrop-filter: blur(10px);
}
```

### 4. 动画时间线（animation-timeline）
- **核心能力**：无需JS，绑定动画到“滚动”或“视口可见性”。
- **两种类型**：
  - `scroll()`：绑定页面滚动（如滚动进度条）；
  - `view()`：绑定元素视口可见性（如元素入视口淡入放大）。
- **面试记忆示例**：滚动进度条
```css
.progress-bar {
  height: 3px; background: #ff6700; width: 0%;
  animation: grow 1s linear forwards;
  animation-timeline: scroll(); /* 绑定滚动 */
}
@keyframes grow { 100% { width: 100%; } }
```

### 5. CSS变量 + calc() 计算函数
- **CSS变量**：
  - 定义：`--变量名: 值`（全局`:root`，局部特定选择器）；
  - 使用：`var(--变量名, 默认值)`；
  - 场景：主题切换、统一样式复用。
- **calc()**：混合单位运算（加减乘除两侧必须留空格），如`calc(100% - 40px)`。
- **面试记忆示例**：主题切换（核心）
```css
:root { --theme-color: #ff6700; }
.dark { --theme-color: #4ecdc4; }
.btn { background: var(--theme-color); }
/* JS切换：document.documentElement.classList.toggle('dark') */
```

### 6. 视口单位 vw/vh
- **定义**：1vw=视口宽度1%，1vh=视口高度1%，适配响应式布局。
- **场景**：全屏banner（`height: 100vh`）、响应式字体（`font-size: 5vw`）。
- **注意**：搭配`min/max-*`限制极端尺寸（如`min-font-size: 24px`）。

## 二、高频面试题（问答形式）
### 1. 请说说SVG动画的核心实现方式，比如“画笔绘制”效果？
**答**：  
核心是利用`stroke-dasharray`（定义虚线模式）和`stroke-dashoffset`（虚线偏移量）配合动画实现：  
1. 先通过JS的`getTotalLength()`获取SVG路径的总长度；  
2. 初始时将`stroke-dasharray`和`stroke-dashoffset`都设为路径长度，让描边完全隐藏；  
3. 定义`@keyframes`动画，将`stroke-dashoffset`逐步减到0，模拟画笔沿路径绘制的效果。  
SVG的优势是矢量无损缩放，适合做图标动画，且主流浏览器原生支持。

### 2. CSS实现毛玻璃效果的核心属性和注意事项？
**答**：  
核心用`backdrop-filter`属性（区别于`filter`：`filter`作用于元素自身，`backdrop-filter`作用于元素背后背景），步骤：  
1. 给元素设置半透明背景（如`rgba(255,255,255,0.6)`），否则滤镜无视觉效果；  
2. 添加`backdrop-filter: blur(10px)`实现模糊，Safari浏览器需加`-webkit-`前缀；  
3. 可选加阴影增强层次感（`box-shadow`）。

### 3. CSS变量的作用域和使用场景？
**答**：  
CSS变量（自定义属性）以`--`开头，分为两种作用域：  
1. 全局作用域：在`:root`（HTML根元素）中定义，作用于整个页面所有元素，适合全局样式（如主题色、基础尺寸）；  
2. 局部作用域：在特定选择器内定义，仅作用于该元素及其子元素，适合组件内样式（如卡片背景色）。  
使用语法是`var(--变量名, 默认值)`，默认值可选。  
核心场景：主题切换（修改变量值即可切换整套样式）、响应式布局（配合calc()动态计算尺寸）、样式复用（减少重复代码）。

### 4. clip-path的作用和兼容性注意事项？
**答**：  
`clip-path`用于创建自定义裁剪区域，仅显示元素在区域内的部分，支持内置形状（circle/ellipse/polygon）和自定义路径，常用于特殊形状的图片、卡片展示。  
兼容性：Safari浏览器需要添加`-webkit-`前缀（如`-webkit-clip-path: polygon(...)`）；另外注意，裁剪仅改变视觉显示，元素实际占位和交互区域仍为原盒子大小。

### 5. animation-timeline是什么？举例说明应用场景？
**答**：  
`animation-timeline`是CSS新特性，可将动画进度绑定到页面滚动（`scroll()`）或元素视口可见性（`view()`），无需JavaScript即可实现交互驱动动画：  
- 滚动绑定场景：滚动进度条（进度条宽度随页面滚动从0到100%）；  
- 视口绑定场景：元素进入视口时淡入、放大（如列表图片入视口后opacity从0.2到1，scale从1到1.05）。

### 6. vw/vh和%单位的区别？使用vw时要注意什么？
**答**：  
- 区别：%单位相对父元素尺寸，vw/vh相对浏览器可视区域尺寸（1vw=视口宽度1%，1vh=视口高度1%）；比如父元素宽度500px，子元素设`width: 50%`是250px；而视口宽度1920px时，`width: 50vw`是960px，和父元素无关。  
- 注意事项：使用vw设置字体/尺寸时，需搭配`min-font-size`/`max-width`等限制极端尺寸，避免在小屏设备上尺寸过小，或大屏设备上尺寸过大。

### 7. calc()函数的使用规则和常见场景？
**答**：  
`calc()`用于CSS中执行数学运算，支持加减乘除，核心规则：加减乘除符号两侧必须保留空格（如`calc(100% - 40px)`，不能写成`calc(100%-40px)`）；支持混合单位（px/%/vw等）。  
常见场景：  
1. 自适应宽度（如卡片宽度`calc(100% - 40px)`，扣除左右边距）；  
2. 配合CSS变量计算（如`calc(var(--base-height) * 1.5)`）；  
3. 响应式布局中动态计算尺寸。

### 8. 综合题：如何实现一个“滚动时导航栏变成毛玻璃，菜单项延迟滑入”的效果？
**答**：  
分两部分实现：  
#### （1）滚动触发毛玻璃导航
```css
.nav {
  position: fixed; width: 100%;
  background: rgba(255,255,255,1); /* 初始不透明 */
  transition: all 0.3s;
}
/* 滚动后添加类名（JS实现） */
.nav.glass {
  background: rgba(255,255,255,0.7);
  -webkit-backdrop-filter: blur(8px);
  backdrop-filter: blur(8px);
}
```
```js
// 监听滚动
window.onscroll = () => {
  const nav = document.querySelector('.nav');
  window.scrollY > 50 ? nav.classList.add('glass') : nav.classList.remove('glass');
};
```
#### （2）菜单项延迟滑入
```html
<ul class="menu">
  <li style="--i: 0">主页</li>
  <li style="--i: 1">关于</li>
</ul>
```
```css
.menu li {
  opacity: 0; transform: translateX(-20px);
  transition: all 0.5s;
  transition-delay: calc(0.1s * var(--i)); /* 延迟递增加载 */
}
.nav.glass .menu li {
  opacity: 1; transform: translateX(0);
}
```

## 三、记忆口诀（辅助背诵）
1. SVG动画：取长度→藏描边→动画归0；  
2. 毛玻璃：半透明背景+backdrop-blur+webkit前缀；  
3. 变量calc：--定义var用，运算空格不能少；  
4. 视口单位：vw宽vh高，min/max来兜底；  
5. 时间线：scroll绑滚动，view绑视口，无需JS动。
