# 前端面试-网页布局核心知识总结（高频考点）
## 一、布局体系核心总结（速记版）
### 1. 布局类型对比（面试必背）
| 布局类型       | 核心特点                | 适用场景                  | 核心考点                  |
|----------------|-------------------------|---------------------------|---------------------------|
| 正常布局流     | 块级垂直、行内水平      | 基础文档结构              | 块级/行内元素默认特性     |
| display转换    | 改显示模式              | 按钮组、小图标            | inline-block空白缝隙解决  |
| 浮动（float）  | 脱离文档流、左右浮动    | 图文环绕、旧版同行布局    | 父容器高度塌陷+清除浮动   |
| 弹性布局（flex）| 一维布局、灵活对齐      | 导航栏、卡片、表单        | 容器/项目属性、垂直居中   |
| 定位（position）| 精准控位置、可层叠      | 弹窗、吸顶、固定导航      | 子绝父相、居中、z-index   |
| 网格布局（grid）| 二维布局、行列同时控制  | 页面框架、响应式多列      | 自动响应式列、跨行列布局  |
| 多列布局（column）| 文本自动分栏        | 长文章分栏                | 跨列切断问题解决          |

### 2. 高频考点速记
#### （1）display 模式转换
- **inline-block 空白缝隙**：父元素设 `font-size: 0`，子元素恢复字号
  ```css
  .btn-group { font-size: 0; }
  .btn { display: inline-block; font-size: 16px; }
  ```

#### （2）浮动布局（核心：清除浮动）
- 问题：父容器高度塌陷、影响后续布局
- 最优方案：双伪元素法（小米/大厂常用）
  ```css
  .clearfix::before, .clearfix::after {
    content: "";
    display: table; /* 解决margin塌陷 */
  }
  .clearfix::after { clear: both; }
  ```

#### （3）Flex 布局（面试最高频）
- 核心：父容器控制子项目，一维布局
- 必考属性：
  - 容器：`justify-content`（主轴对齐）、`align-items`（交叉轴单行）、`gap`（间距）
  - 项目：`flex: 1`（等比分配剩余空间）、`align-self`（单独对齐）
- 经典场景：垂直居中
  ```css
  .container { display: flex; align-items: center; justify-content: center; }
  ```

#### （4）定位布局（核心：子绝父相）
- 子绝父相：子元素`absolute`（脱离流），父元素`relative`（做定位基准）
- 绝对定位居中（无需知宽高，推荐）：
  ```css
  .child {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
  }
  ```
- z-index：仅对定位元素生效，数值越大越靠上（弹窗>遮罩）

#### （5）Grid 布局（响应式高频）
- 自动适配列数（无需媒体查询）：
  ```css
  .container {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(210px, 1fr));
    gap: 16px;
  }
  ```

## 二、面试常见题目（问答版）
### 1. 基础类
#### Q1：块级元素和行内元素的区别？
A：
- 块级：独占一行，宽默认撑满父容器，可设宽高（如div、p、h1）；
- 行内：水平排列，宽高由内容决定，不可设宽高/垂直边距（如span、a）；
- 补充：inline-block 兼具两者特点（同行+可设宽高），但有空白缝隙问题。

#### Q2：浮动布局有什么问题？如何解决？
A：
- 问题：① 父容器高度塌陷（浮动元素不占空间）；② 挤压/覆盖后续标准流元素；
- 解决方法（按优先级）：
  1. 双伪元素法（推荐）：给父容器加.clearfix类（代码见上文）；
  2. overflow法：父容器设`overflow: hidden/auto`（注意：可能隐藏溢出内容）；
  3. 额外标签法：浮动元素后加`<div style="clear: both"></div>`（冗余，仅调试用）。

### 2. Flex 布局类
#### Q3：Flex 布局的主轴和交叉轴怎么控制？常用对齐方式有哪些？
A：
- 主轴：由`flex-direction`控制（row/row-reverse/column/column-reverse）；
- 交叉轴：与主轴垂直，默认垂直方向；
- 对齐方式：
  - 主轴：`justify-content`（center/space-between/space-around）；
  - 交叉轴：单行用`align-items`，多行用`align-content`；
- 经典场景：导航栏左右分布（左侧logo，右侧菜单）
  ```css
  .nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
  }
  ```

#### Q4：flex: 1 代表什么意思？
A：`flex: 1` 是 `flex-grow: 1; flex-shrink: 1; flex-basis: auto` 的简写：
- flex-grow: 1：剩余空间按1份分配；
- flex-shrink: 1：空间不足时等比缩小；
- flex-basis: auto：初始宽度由内容决定。

### 3. 定位布局类
#### Q5：position 的取值有哪些？区别是什么？
A：
| 取值     | 脱离文档流 | 定位基准                | 典型场景          |
|----------|------------|-------------------------|-------------------|
| static   | 否         | 默认文档流（无定位）    | 普通元素          |
| relative | 否         | 自身原位置              | 微调位置、子绝父相 |
| absolute | 是         | 最近的非static祖先/视口 | 弹窗、下拉菜单    |
| fixed    | 是         | 浏览器视口（滚动不变）  | 固定导航、返回顶部 |
| sticky   | 否         | 视口（滚动到阈值固定）  | 吸顶导航          |

#### Q6：实现吸顶导航的两种方式？
A：
1. position: sticky（推荐）：`nav { position: sticky; top: 0; z-index: 999; }`；
2. position: fixed + 监听滚动（兼容旧浏览器）：JS监听scroll事件，动态添加fixed类。

### 4. 综合类
#### Q7：Flex 和 Grid 的区别？分别适用于什么场景？
A：
- Flex：一维布局（仅控制行/列单方向），适合“单行/单列”布局（导航栏、表单对齐、卡片列表）；
- Grid：二维布局（同时控制行+列），适合复杂页面框架（如首页三分栏、不规则分栏、响应式多列卡片）；
- 补充：简单布局用Flex（代码少），复杂二维布局用Grid（更灵活）。

#### Q8：如何实现一个水平垂直居中的弹窗？
A：（推荐方案，无需知弹窗宽高）
```css
.mask { /* 遮罩层 */
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: rgba(0,0,0,0.5);
}
.modal { /* 弹窗 */
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 400px;
  background: #fff;
  padding: 20px;
}
```

#### Q9：CSS 书写顺序的规范？
A：按“布局→盒模型→视觉→交互→其他”：
1. 布局：display/position/float/overflow/z-index；
2. 盒模型：width/height/margin/padding/border；
3. 视觉：color/background/font/text-align；
4. 交互：cursor/transition/animation；
5. 其他：filter/transform。

## 三、记忆技巧
1. 优先记“场景+解决方案”（面试多结合场景提问）；
2. Flex/定位/浮动是高频中的高频，必须背熟核心代码示例；
3. 用“对比法”记忆：比如Flex（一维）vs Grid（二维）、absolute（相对祖先）vs fixed（相对视口）。
